プライバシーポリシー

Lunar Tear — 非公式・保存用サーバー

Version: {{VERSION}}

1. 保存する情報

  • 端末が生成するアカウント識別子およびセッションキー。
  • ゲームの進行データ（キャラクター・アイテム・クエストなど）。
  • 障害対応のための最低限の技術ログ。

2. 行わないこと

  • 広告・第三者解析・トラッキング SDK の使用はありません。
  • データの販売や第三者への提供は行いません。
  • 決済情報の取得は行いません（購入処理は発生しません）。

3. 保存と安全性

データは本サーバー上にのみ保存されます。コミュニティサービスであるため、安全性や 可用性は保証されません。

4. 削除

アカウントデータの削除は、運営者にいつでも依頼できます。
